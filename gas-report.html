🛠️ Optimization Techniques Applied

1. Custom Errors (30+ conversions)

💰 −317,000 gas deployment | −50 gas/revert

Replaced all require("string") with custom errors. Strings stored in bytecode cost ~200 gas/byte on deploy. Custom errors use only a 4-byte selector.

- require(org != address(0), "Event non-existent"); + if (org == address(0)) revert EventNotFound();

2. Merged Double Loop (Batch Buy)

💰 −2,100 gas per tier (avoided SLOAD)

Original had 2 loops reading each tier from storage twice. Merged into single loop — validate + mint in one pass. Each avoided cold SLOAD saves 2,100 gas.

- Loop 1: validate tiers (read storage) - Loop 2: mint tickets (read SAME storage again) + Single loop: validate + mint (read once)

3. Aggregated Storage Writes

💰 −5,000 gas per extra tier in batch

Instead of writing eventTicketsSold inside each tier iteration (5,000 gas each SSTORE), accumulate in memory and write once after the loop.

- for each tier: eventTicketsSold += qty; // N writes + totalMinted += qty; // memory (free) + eventTicketsSold += totalMinted; // 1 write

4. Assembly ETH Transfers

💰 −100-200 gas per transfer (6 call sites)

Solidity's .call{value:}("") copies return data unnecessarily. Assembly call() skips return data handling entirely.

- (bool s,) = payable(to).call{value: amt}(""); + assembly { call(gas(), to, amt, 0, 0, 0, 0) }

5. Assembly Nonce Generation

💰 −100-200 gas per mint

abi.encodePacked() allocates new memory each call. Assembly writes to scratch space (0x00-0x7F) directly — no memory allocation.

- keccak256(abi.encodePacked(a, b, c, d)) + assembly { mstore(0x00,a); mstore(0x20,b); + mstore(0x40,c); mstore(0x60,d); + nonce := keccak256(0x00, 0x80) }

6. calldata vs memory Parameters

💰 −200-600 gas per array parameter

External functions with memory arrays copy calldata→memory unnecessarily. calldata reads directly from tx input at 3 gas per word.

- function createEvent(string memory, uint256[] memory) + function createEvent(string calldata, uint256[] calldata)

7. Storage Read Caching

💰 −100-2,100 gas per cached read

Cached evt.organiser, t.sold, t.price in local variables. Each avoided warm SLOAD saves 100 gas; cold SLOAD saves 2,100.

- if (evt.organiser == ...) // SLOAD - payable(evt.organiser) // SLOAD again + address org = evt.organiser; // 1 SLOAD + if (org == ...) _sendETH(org, ...) // free

8. unchecked Arithmetic

💰 −30-60 gas per operation

Solidity 0.8+ adds overflow checks to every math op. For counters and bounded values that can never overflow, we skip these with unchecked.

+ unchecked { t.sold = soldCount + 1; + eventTicketsSold[eventId]++; + nextTokenId = tokenId + 1; }

9. public → external Views

💰 Cheaper for external callers

10 view functions changed. public copies params to memory for internal call compat. external skips this copy since only called from outside.

10. Removed Redundant Bounds Checks

💰 −200 gas per buy

Solidity already checks array bounds on access. Our explicit tierId >= length check was redundant — double-checking the same thing.

11. Restructured Referral Logic

💰 Avoids SLOAD when referrer is invalid

Split the referral condition into nested ifs. Cheap address comparisons run first; the expensive storage read (eventReferrals) only runs if all address checks pass.
